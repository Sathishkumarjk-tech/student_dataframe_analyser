# Student Data Frame Analyzer

**Aim:** Demonstrate data-frame operations and statistical summaries in R.

**Features:** Creates student records, assigns pass/fail and grades, calculates summary statistics, creates frequency tables, filters passed students, and exports a CSV report.

**Concepts:** `data.frame()`, `ifelse()`, `mean()`, `max()`, `min()`, `table()`, `factor()`, filtering, and `write.csv()`.

**Run:** Open the folder in RStudio and run `source("main.R")`.
